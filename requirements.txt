# One TensorFlow version everywhere (2.16.1), three markers so every machine
# gets the right build and NO machine is left without one:
#   linux + x86_64  -> the [and-cuda] extra, which pulls the CUDA 12.3 / cuDNN
#                      wheels the VM's T4 needs. Plain `tensorflow` on Linux
#                      imports fine but silently falls back to CPU -- 'Cannot
#                      dlopen some GPU libraries' is the only warning you get.
#   linux + arm64   -> plain tensorflow. This is the Docker build on an Apple
#                      Silicon Mac; there are no CUDA wheels for arm64, and
#                      without this line pip installs NO tensorflow at all.
#   everything else -> plain tensorflow (macOS, Windows); macOS arm64 also
#                      picks up tensorflow-metal below.
tensorflow[and-cuda]==2.16.1; sys_platform == 'linux' and platform_machine == 'x86_64'
tensorflow==2.16.1; sys_platform == 'linux' and platform_machine != 'x86_64'
tensorflow==2.16.1; sys_platform != 'linux'
